Platform Features

Everything you need to manage
a dark store network

Real-time Dispatch

Orders are routed the instant they arrive. The selected algorithm runs in milliseconds and returns the optimal warehouse immediately.

Geo-aware Routing

The Nearest Warehouse algorithm uses the Haversine formula to calculate real-world distances accounting for Earth's curvature.

Live Load Dashboard

Monitor every warehouse in real time — capacity usage, order counts, load percentage, and algorithm breakdown, all in one view.

Algorithm Simulator

Run all four algorithms on the same customer location simultaneously and compare which warehouse each one selects — perfect for viva demos.

Warehouse CRUD

Add, edit, and remove dark stores from the network. Toggle active, inactive, or maintenance status — changes reflect instantly in routing.

SQLite Backend

Zero-config SQL database using better-sqlite3. All data persists locally — no cloud DB needed, no external dependencies, instant queries.

Core Algorithms

Four strategies. One goal:
optimal order assignment.

01
Nearest Warehouse

Uses the Haversine formula to compute great-circle distance between the customer's GPS coordinates and every active warehouse. Picks the closest one with available capacity.

O(n) Geo-aware Min. delivery time
02
Round Robin

Cycles through active warehouses in sequence — each gets a turn before any gets a second. Simple, fair, and stateless. The index is tracked in memory and resets on restart.

O(1) Fair distribution Stateless
03
Weighted Round Robin

Proportional to capacity — a 200-slot warehouse gets exactly twice as many orders as a 100-slot one. Implemented using the classic GCD-based weight cycling algorithm.

O(n) Capacity-proportional Heterogeneous fleets
04
Least Loaded

Scans all active warehouses and picks the one with the largest number of free slots (capacity − currentOrders). Prevents any single node from becoming a bottleneck.

O(n) Anti-bottleneck Max free capacity
